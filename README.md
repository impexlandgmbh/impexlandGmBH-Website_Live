# IMPEX LAND corporate website

Bilingual static website with German as the default language. German and English content is adapted from the supplied company portfolio. The original IMPEX LAND logo is retained.

## Pages
Startseite/Home, Leistungen/Services, Branchen & Märkte/Industries & Markets, Über uns/About Us, Kontakt/Contact, Impressum and Datenschutz/Privacy. Hash routes preserve the selected language and service deep links.

## Contact behavior
The form validates required fields and opens a mailto draft. It does not store or send submissions. A mail service integration is required before replacing this with automatic submission.

## Run normally

1. Extract the ZIP file.
2. Open the `IMPEX_LAND_Website_Double_Click` folder.
3. Double-click `index.html`.

No installation, terminal command or local server is required. You can also open the folder in Visual Studio Code and double-click `index.html` from Windows File Explorer. Edit `app.js` for the main website content and `details.js` for service-detail and legal-page content.
